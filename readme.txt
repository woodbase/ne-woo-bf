== Description ==
NE Beautyfort Woo is a WordPress plugin that enables seamless product synchronization with WooCommerce. It provides an administrative dashboard for plugin management and includes a test mode feature that connects to the Beautyfort test environment. The plugin is built with a clean structure and an MVC-like architecture, ready for future expansion.

== Installation ==
1. Download the zip file from the GitHub Release.
2. Log in to your WordPress admin.
3. Go to Plugins > Add New > Upload Plugin.
4. Select the zip file and click Install Now.
5. Activate the plugin.

== Frequently Asked Questions ==
= How does test mode work? =
Test mode connects the plugin to the Beautyfort test environment, allowing you to safely try synchronization and other features without affecting live WooCommerce data.

= Can I sync selected products only? =
Yes, you can choose which products to sync directly in the admin dashboard.
